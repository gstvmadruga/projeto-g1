🧩 Sobre o Projeto

Este projeto tem como objetivo analisar dados simulados de redes sociais brasileiras utilizando Python e ferramentas de análise e visualização de dados.

A análise compara diferentes plataformas, perfis, categorias e tipos de conteúdo, utilizando métricas como seguidores, curtidas, comentários, compartilhamentos, visualizações, alcance e taxa de engajamento.

🎯 Objetivos

  • Realizar análise exploratória dos dados;
  • Realizar a limpeza e preparação da base;
  • Criar novas métricas;
  • Calcular indicadores de desempenho (KPIs);
  • Criar visualizações dos resultados;
  • Analisar a correlação entre as principais métricas;
  • Utilizar banco de dados SQLite com SQLAlchemy;
  • Desenvolver um dashboard interativo.

🛠️ Tecnologias Utilizadas

Python Pandas Matplotlib Seaborn Streamlit SQLAlchemy SQLite Jupyter Notebook GitHub

📊 Dashboard

O projeto possui um dashboard interativo desenvolvido com Streamlit, permitindo a aplicação de filtros, visualização de KPIs, gráficos e consulta dos dados das publicações.
