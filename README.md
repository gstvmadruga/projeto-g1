## 🧩 Sobre o Projeto

Este projeto tem como objetivo realizar uma análise de dados simulados de redes sociais brasileiras utilizando Python e ferramentas de análise e visualização de dados.

A análise busca identificar padrões de desempenho entre diferentes plataformas, perfis, categorias e tipos de conteúdo, utilizando métricas como seguidores, curtidas, comentários, compartilhamentos, visualizações, alcance e taxa de engajamento.

Os resultados são apresentados por meio de análise exploratória, indicadores de desempenho (KPIs), gráficos, análise de correlação e um dashboard interativo.

---

## 🎯 Objetivos

- Realizar análise exploratória dos dados;
- Realizar a limpeza e preparação da base;
- Criar novas métricas a partir dos dados;
- Calcular indicadores de desempenho (KPIs);
- Criar visualizações dos resultados;
- Analisar a evolução da taxa de engajamento ao longo dos anos;
- Analisar a relação entre seguidores e taxa de engajamento;
- Analisar a correlação entre as principais métricas;
- Utilizar banco de dados SQLite com SQLAlchemy;
- Desenvolver um dashboard interativo com Streamlit;
- Publicar o projeto na internet.
